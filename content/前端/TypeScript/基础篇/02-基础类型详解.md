# TypeScript 基础类型详解

## 一、类型注解基础

### 1.1 什么是类型注解？

TypeScript 最重要的特性就是**静态类型系统**，通过**类型注解**（Type Annotation）来标记变量的类型。

```typescript
// 语法：变量名: 类型
let name: string = 'TypeScript'
let age: number = 10
```

### 1.2 类型推论（Type Inference）

TS 会自动推断类型，不是所有地方都需要写注解：

```typescript
// ✅ 自动推断为 string
let message = 'hello'  // 等同于 let message: string = 'hello'

// ✅ 自动推断为 number[]
let numbers = [1, 2, 3]

// ✅ 函数返回值也能推断
function add(a: number, b: number) {
  return a + b  // 自动推断返回 number
}
```

> 💡 原则：能推断就不用手动写注解！

## 二、原始类型（Primitive Types）

### 2.1 string 字符串

```typescript
let str: string = 'hello'

// 模板字符串
let name: string = `Hello, ${str}!`

// 字符串字面量类型
let gender: 'male' | 'female' = 'male'
```

---

### 2.2 number 数字

```typescript
let num: number = 42
let float: number = 3.14
let hex: number = 0xf00d        // 十六进制
let binary: number = 0b1010     // 二进制
let octal: number = 0o744       // 八进制

// ES2020 BigInt
let big: bigint = 100n
```

---

### 2.3 boolean 布尔值

```typescript
let isDone: boolean = false
let hasError: boolean = true
```

---

### 2.4 null 和 undefined

```typescript
let u: undefined = undefined
let n: null = null

// ⚠️  strictNullChecks: true 时，null/undefined 只能赋值给自己
let str: string = null   // ❌ 报错！

// 可能为 null 的情况
let maybeString: string | null = null
maybeString = 'hello'  // ✅
```

---

### 2.5 symbol

```typescript
// 唯一符号
let sym1: symbol = Symbol()
let sym2: symbol = Symbol('key')

// 用作对象键
const KEY = Symbol()
let obj = {
  [KEY]: 'value'
}
```

## 三、数组类型（Array）

### 3.1 两种写法

```typescript
// 写法一：类型 + []（推荐）
let numbers: number[] = [1, 2, 3]
let strings: string[] = ['a', 'b', 'c']

// 写法二：泛型写法
let numbers2: Array<number> = [1, 2, 3]
```

### 3.2 数组方法的类型检查

```typescript
let arr: number[] = [1, 2, 3]

arr.push(4)      // ✅
arr.push('5')     // ❌ 字符串不能加入数字数组

arr.map(num => {
  num.toFixed(2)  // ✅ num 自动是 number 类型
})
```

### 3.3 只读数组

```typescript
// readonly 修饰，不能 push/pop/splice
let readonlyArr: readonly number[] = [1, 2, 3]
readonlyArr.push(4)  // ❌

// 或者 Readonly 泛型
let roArr: ReadonlyArray<number> = [1, 2, 3]
```

## 四、元组类型（Tuple）

### 4.1 基本用法

**固定长度 + 固定类型的数组**：

```typescript
// 定义一个元组：[string, number]
let person: [string, number] = ['Tom', 25]

// ✅ 正确
person[0] = 'Jerry'  // string
person[1] = 30        // number

// ❌ 错误
person[0] = 123      // 类型不对
person[2] = true      // 越界
```

### 4.2 可选元素和剩余元素

```typescript
// 可选元素
let point: [number, number?] = [10]

// 剩余元素
let list: [string, ...number[]] = ['hello', 1, 2, 3]

// 只读元组
let point2: readonly [number, number] = [10, 20]
```

### 4.3 常见使用场景

```typescript
// useState 返回值类型
function useState<T>(initial: T): [T, (val: T) => void] {
  // ...
}

const [count, setCount] = useState(0)
// count: number
// setCount: (val: number) => void
```

## 五、对象类型（Object）

### 5.1 对象字面量写法

```typescript
// 直接定义对象结构
let user: {
  name: string
  age: number
  email?: string  // ? 表示可选属性
} = {
  name: 'Tom',
  age: 25
  // email 可选，可以不写
}
```

### 5.2 可选属性与只读属性

```typescript
let config: {
  readonly apiKey: string  // 只读，不能修改
  timeout?: number          // 可选
  retries: number | undefined  // 和 ? 等价
} = {
  apiKey: 'xxx-xxx'
}

config.apiKey = 'new-key'  // ❌ 只读不能改
```

## 六、函数类型

### 6.1 函数参数与返回值

```typescript
// 完整写法
function add(a: number, b: number): number {
  return a + b
}

// 箭头函数
const multiply = (a: number, b: number): number => a * b

// 无返回值：void
function log(message: string): void {
  console.log(message)
  // return undefined 是可以的
}

// 永不返回：never
function throwError(message: string): never {
  throw new Error(message)
  // 不会执行到这里
}
```

### 6.2 可选参数与默认参数

```typescript
// 可选参数（必须在必选参数后面）
function greet(name: string, greeting?: string): string {
  return `${greeting || 'Hello'}, ${name}!`
}

greet('Tom')           // ✅
greet('Tom', 'Hi')     // ✅

// 默认参数
function greet2(name: string, greeting: string = 'Hello'): string {
  return `${greeting}, ${name}!`
}
```

### 6.3 剩余参数

```typescript
function sum(...numbers: number[]): number {
  return numbers.reduce((a, b) => a + b, 0)
}

sum(1, 2, 3)  // ✅
sum('1')       // ❌
```

## 七、特殊类型

### 7.1 any - 任意类型

```typescript
// ❌ 避免使用 any！回到 JS 的世界
let anything: any = 'hello'
anything = 42
anything = true
anything.nothing.exists()  // 编译不报错，运行时炸
```

> 💡 能用具体类型就不用 any，实在不确定用 `unknown`

---

### 7.2 unknown - 未知类型

```typescript
// ✅ 类型安全的 any
let value: unknown = 'hello'
value = 42
value = true

// ❌ 不能直接操作 unknown
value.toFixed()  // 报错！

// ✅ 必须先类型收窄才能用
if (typeof value === 'number') {
  value.toFixed()  // ✅
}
```

**any vs unknown 对比**：

| 操作 | any | unknown |
|------|-----|---------|
| 任意赋值 | ✅ | ✅ |
| 任意操作 | ✅ | ❌（需收窄 |
| 类型安全 | ❌ | ✅ |

---

### 7.3 void - 无返回值

```typescript
// 函数没有 return 或只 return 没有值
function log(msg: string): void {
  console.log(msg)
}

// void 函数可以返回 undefined
function noop(): void {
  return undefined
}
```

---

### 7.4 never - 永不返回

```typescript
// 抛出异常，永远不会返回
function error(message: string): never {
  throw new Error(message)
}

// 无限循环
function infiniteLoop(): never {
  while (true) {}
}

// 穷尽检查（很有用！）
type Shape = 'circle' | 'square'

function getArea(shape: Shape): number {
  switch (shape) {
    case 'circle': return Math.PI * r * r
    case 'square': return side * side
    default:
      // 如果漏掉了某个 case，这里会报错！
      const _exhaustiveCheck: never = shape
      return _exhaustiveCheck
  }
}
```

## 八、联合类型（Union Types）

### 8.1 基础用法

```typescript
// 用 | 连接多个类型
let id: string | number

id = 'abc123'  // ✅
id = 12345     // ✅
id = true       // ❌
```

### 8.2 联合类型的操作

```typescript
function printId(id: string | number) {
  // ❌ 不能直接调用只有 string 有的方法
  id.toUpperCase()

  // ✅ 必须先收窄类型
  if (typeof id === 'string') {
    id.toUpperCase()  // string 方法
  } else {
    id.toFixed()      // number 方法
  }
}
```


### 9.3 布尔字面量

```typescript
let isTrue: true

```

## 十、类型断言（Type Assertion）

### 10.1 as 语法

```typescript
// 你比 TS 更清楚类型时使用
let value: unknown = 'hello world'

// 断言为 string
let strLength: number = (value as string).length
```

### 10.2 尖括号语法（不推荐，JSX 中冲突）

```typescript
let strLength: number = (<string>value).length
```

### 10.3 非空断言 `!`

```typescript
let maybeString: string | null = getString()

// 你确定它一定不是 null/undefined
let length: number = maybeString!.length
```

> ⚠️ 谨慎使用！断言相当于告诉编译器："相信我，我知道我在做什么"

## 十一、类型别名（Type Alias）

```typescript
// 给类型起个名字
type ID = string | number

type User = {
  id: ID
  name: string
  age: number
}

let user: User = {
  id: 123,
  name: 'Tom',
  age: 25

```

## 十二、常见问题

### Q1：什么时候需要写类型注解？

- TS 推断不出来的时候
- 需要更宽泛的类型时
- 函数参数（除非有默认值）

### Q2：`string` vs `String` 区别？

```typescript
let s1: string = 'hello'   // ✅ 原始类型，推荐
let s2: String = new String('hello')  // 包装对象，不用
```

### Q3：怎么选择 any 和 unknown？

- 永远优先用 `unknown`
- `any` 是逃避类型检查，`unknown` 是类型安全的

## 总结

**原始类型**：`string`, `number`, `boolean`, `null`, `undefined`, `symbol`, `bigint`

**复合类型**：`array`, `tuple`, `object`, `function`

**特殊类型**：`any`, `unknown`, `void`, `never`

**操作符**：`|` 联合类型，`as` 类型断言
