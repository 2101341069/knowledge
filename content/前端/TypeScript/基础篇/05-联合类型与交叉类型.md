# 联合类型与交叉类型

## 一、联合类型（Union Types）

### 1.1 基本概念

联合类型使用 `|` 运算符，表示一个值可以是**几种类型之一**。

```typescript
// A 或者 B
type A = string | number

let id: A = 'abc'   // ✅
let id2: A = 123    // ✅
let id3: A = true   // ❌
```

---

### 1.2 使用场景

```typescript
// 函数参数接受多种类型
function formatId(id: string | number): string {
  return String(id)
}

// API 返回值可能是数组或 null
type UserList = User[] | null

// 表单字段值
type FormValue = string | number | boolean | null
```

---

### 1.3 联合类型的操作——类型收窄

使用联合类型时，只能使用**所有成员类型的公共方法**：

```typescript
function process(value: string | number) {
  // ❌ 不能直接用，因为 number 没有 toUpperCase
  value.toUpperCase()

  // ✅ 类型收窄后再操作
  if (typeof value === 'string') {
    value.toUpperCase()   // string 方法
  } else {
    value.toFixed(2)      // number 方法
  }
}
```

---

### 1.4 字面量联合类型

```typescript
// 字符串字面量联合
type Direction = 'up' | 'down' | 'left' | 'right'
type Status = 'pending' | 'approved' | 'rejected'
type Color = 'red' | 'green' | 'blue'

// 数字字面量联合
type DiceValue = 1 | 2 | 3 | 4 | 5 | 6
type HttpCode = 200 | 201 | 400 | 401 | 403 | 404 | 500

// 混合字面量联合
type Toggle = true | false | 'auto'
```

---

### 1.5 可辨识联合（Discriminated Unions）

通过一个公共的**字面量类型字段**来区分联合类型的各个成员。

```typescript
// 每个成员有相同名字但不同值的字段（tag/discriminant）
type Circle = {
  kind: 'circle'   // ← 可辨识字段
  radius: number
}

type Square = {
  kind: 'square'   // ← 可辨识字段
  side: number
}

type Triangle = {
  kind: 'triangle' // ← 可辨识字段
  base: number
  height: number
}

type Shape = Circle | Square | Triangle

function getArea(shape: Shape): number {
  switch (shape.kind) {
    case 'circle':
      return Math.PI * shape.radius ** 2
    case 'square':
      return shape.side ** 2
    case 'triangle':
      return (shape.base * shape.height) / 2
    default:
      // 穷尽检查：如果漏写了某个 case，这里会报错
      const _never: never = shape
      throw new Error('Unknown shape')
  }
}
```

> 💡 可辨识联合是 TypeScript 中处理多态的最佳实践，比 if-else 链更安全。

---

### 1.6 联合类型与数组

```typescript
// 数组元素是联合类型
type MixedArray = (string | number)[]

const arr: MixedArray = [1, 'hello', 2, 'world']  // ✅

// 联合数组：数组本身是联合类型
type StringArray = string[]
type NumberArray = number[]
type MixedType = StringArray | NumberArray  // 要么全是 string[]，要么全是 number[]
```

## 二、交叉类型（Intersection Types）

### 2.1 基本概念

交叉类型使用 `&` 运算符，将多个类型**合并为一个**，结果类型具有所有成员类型的属性。

```typescript
type A = { name: string }
type B = { age: number }

// A 与 B 的交叉
type AB = A & B
// 等同于 { name: string; age: number }

const obj: AB = {
  name: 'Tom',   // 必须有 A 的属性
  age: 25        // 也必须有 B 的属性
}
```

---

### 2.2 对象类型合并

```typescript
type HasId = { id: number }
type HasName = { name: string }
type HasEmail = { email: string }
type HasTimestamps = { createdAt: Date; updatedAt: Date }

// 组合成完整类型
type User = HasId & HasName & HasEmail & HasTimestamps

const user: User = {
  id: 1,
  name: 'Tom',
  email: 'tom@example.com',
  createdAt: new Date(),
  updatedAt: new Date()
}
```

---

### 2.3 Mixin 模式

交叉类型常用于实现 Mixin（混入）模式：

```typescript
type Serializable = {
  serialize(): string
  deserialize(data: string): void
}

type Loggable = {
  log(message: string): void
  warn(message: string): void
  error(message: string): void
}

type TimestampMixin = {
  createdAt: Date
  updatedAt: Date
  touch(): void
}

// 一个具备所有能力的实体
type FullFeaturedEntity = Serializable & Loggable & TimestampMixin & {
  id: number
  name: string
}
```

---

### 2.4 函数类型交叉（重载效果）

```typescript
type ToStringFunc = {
  (value: string): string
  (value: number): string
  (value: boolean): string
}

// 等同于函数重载
```

---

### 2.5 原始类型交叉的特殊情况

```typescript
// 原始类型交叉后变为 never（无法同时是两种原始类型）
type StringAndNumber = string & number   // never
type A = 'hello' & 'world'             // never（字面量类型不同）
type B = 'hello' & string              // 'hello'（字面量更具体）
```

## 三、联合 vs 交叉：核心区别

| 运算符 | 语义 | 结果属性 | 类比 |
|--------|------|----------|------|
| `\|` 联合 | **或**：满足其中一个 | 只能访问公共属性 | 集合的**并集** |
| `&` 交叉 | **且**：必须同时满足 | 可以访问所有属性 | 集合的**交集** |

```typescript
type A = { x: number; y: number }
type B = { y: number; z: number }

// 联合类型：只能访问 y（共有属性）
type UnionAB = A | B
const u: UnionAB = { x: 1, y: 2 }       // ✅ A 的结构
const u2: UnionAB = { y: 2, z: 3 }      // ✅ B 的结构
// 只能访问 y

// 交叉类型：必须有所有属性
type InterAB = A & B
const i: InterAB = { x: 1, y: 2, z: 3 }  // ✅ 必须包含全部属性
// 可以访问 x、y、z
```

## 四、实战应用

### 4.1 构建可扩展的配置类型

```typescript
// 基础配置
type BaseConfig = {
  host: string
  port: number
}

// 数据库配置
type DatabaseConfig = BaseConfig & {
  database: string
  username: string
  password: string
}

// Redis 配置
type RedisConfig = BaseConfig & {
  password?: string
  db?: number
}

// 应用全局配置
type AppConfig = {
  database: DatabaseConfig
  cache: RedisConfig
  env: 'development' | 'test' | 'production'
}
```

---

### 4.2 权限系统

```typescript
type ReadPermission = { read: true }
type WritePermission = { write: true }
type AdminPermission = { admin: true }

// 不同角色组合权限
type ReadOnly = ReadPermission
type ReadWrite = ReadPermission & WritePermission
type FullAccess = ReadPermission & WritePermission & AdminPermission

function checkAccess(user: ReadWrite, resource: string) {
  if ('admin' in user) {
    // admin 操作
  }
  user.read   // ✅
  user.write  // ✅
}
```

---

### 4.3 React 组件复合 Props

```typescript
// 基础 HTML 属性
type BaseHTMLProps = {
  className?: string
  style?: React.CSSProperties
  id?: string
}

// 事件处理
type ClickableProps = {
  onClick?: () => void
  onDoubleClick?: () => void
}

// 自定义业务属性
type ButtonCustomProps = {
  variant: 'primary' | 'secondary' | 'danger'
  loading?: boolean
  disabled?: boolean
}

// 合并为 Button 组件 Props
type ButtonProps = BaseHTMLProps & ClickableProps & ButtonCustomProps
```

### 4.4 状态处理联合类型

```typescript
// 请求状态
type Loading = { status: 'loading' }
type Success<T> = { status: 'success'; data: T }
type Failure = { status: 'error'; error: string }

type AsyncResult<T> = Loading | Success<T> | Failure

function renderUserProfile(result: AsyncResult<User>) {
  switch (result.status) {
    case 'loading':
      return '<Spinner />'
    case 'success':
      return `<Profile user={${result.data.name}} />`
    case 'error':
      return `<ErrorMessage msg="${result.error}" />`
  }
}
```

## 五、高级技巧

### 5.1 从联合类型中提取特定成员

```typescript
type Actions =
  | { type: 'INCREMENT'; payload: number }
  | { type: 'DECREMENT'; payload: number }
  | { type: 'RESET' }
  | { type: 'SET_USER'; payload: User }

// 提取特定 action
type IncrementAction = Extract<Actions, { type: 'INCREMENT' }>
// { type: 'INCREMENT'; payload: number }

// 排除特定 action
type NonResetActions = Exclude<Actions, { type: 'RESET' }>
```

---

### 5.2 联合类型转交叉类型

```typescript
// 高级技巧：联合转交叉（类型体操）
type UnionToIntersection<U> = 
  (U extends any ? (k: U) => void : never) extends (k: infer I) => void ? I : never

type A = { a: string }
type B = { b: number }
type C = A | B

type D = UnionToIntersection<C>
// { a: string } & { b: number } = { a: string; b: number }
```

## 六、总结

- **联合类型** `|`：or 关系，允许多种类型之一，只能操作公共属性
- **交叉类型** `&`：and 关系，必须满足所有类型，可以操作全部属性
- **可辨识联合**：通过 tag 字段区分联合成员，推荐的类型安全模式
- **联合类型 + switch**：穷尽检查，避免漏掉 case
