# 模板字面量类型（Template Literal Types）

TypeScript 4.1 引入的强大特性，让字符串类型也能进行"运算"。

## 一、基础语法

与 JavaScript 的模板字符串类似，但用于**类型层面**：

```typescript
// JavaScript 模板字符串
const greeting = `Hello, ${'World'}!`  // 'Hello, World!'

// TypeScript 模板字面量类型
type Greeting = `Hello, ${'World'}!`  // 'Hello, World!'
type Dynamic = `Hello, ${string}!`    // `Hello, ${string}!`
```

---

## 二、字符串类型组合

### 2.1 多个联合类型的笛卡尔积

```typescript
type Direction = 'top' | 'right' | 'bottom' | 'left'
type Position = 'start' | 'center' | 'end'

// 自动生成所有组合
type GridPosition = `${Direction}-${Position}`
// 'top-start' | 'top-center' | 'top-end'
// | 'right-start' | 'right-center' | 'right-end'
// | 'bottom-start' | 'bottom-center' | 'bottom-end'
// | 'left-start' | 'left-center' | 'left-end'
```

---

### 2.2 CSS 属性名生成

```typescript
type Side = 'top' | 'right' | 'bottom' | 'left'
type MarginPadding = `${'margin' | 'padding'}-${Side}`
// 'margin-top' | 'margin-right' | 'margin-bottom' | 'margin-left'
// | 'padding-top' | 'padding-right' | 'padding-bottom' | 'padding-left'

// CSS 颜色变量
type ColorScale = 100 | 200 | 300 | 400 | 500 | 600 | 700 | 800 | 900
type ColorName = 'red' | 'blue' | 'green' | 'yellow'
type CSSColorVar = `--color-${ColorName}-${ColorScale}`
// '--color-red-100' | '--color-red-200' | ...
```

## 三、内置字符串操作类型

TypeScript 提供了四个内置的字符串操作类型：

```typescript
// Uppercase<S> - 全部大写
type Upper = Uppercase<'hello world'>  // 'HELLO WORLD'

// Lowercase<S> - 全部小写
type Lower = Lowercase<'HELLO WORLD'>  // 'hello world'

// Capitalize<S> - 首字母大写
type Cap = Capitalize<'hello'>  // 'Hello'

// Uncapitalize<S> - 首字母小写
type Uncap = Uncapitalize<'Hello'>  // 'hello'

// 结合使用
type EventName<T extends string> = `on${Capitalize<T>}`
type ClickEvent = EventName<'click'>  // 'onClick'
type ChangeEvent = EventName<'change'>  // 'onChange'
```

## 四、实用模式

### 4.1 自动生成 getter 类型

```typescript
type Getters<T extends object> = {
  [K in keyof T as `get${Capitalize<string & K>}`]: () => T[K]
}

interface User {
  id: number
  name: string
  email: string
}

type UserGetters = Getters<User>
// {
//   getId: () => number
//   getName: () => string
//   getEmail: () => string
// }
```

---

### 4.2 自动生成事件监听器类型

```typescript
type EventMap = {
  click: MouseEvent
  focus: FocusEvent
  input: InputEvent
  change: Event
}

type EventListeners = {
  [K in keyof EventMap as `on${Capitalize<string & K>}`]: (event: EventMap[K]) => void
}

// {
//   onClick: (event: MouseEvent) => void
//   onFocus: (event: FocusEvent) => void
//   onInput: (event: InputEvent) => void
//   onChange: (event: Event) => void
// }
```

---

### 4.3 深层对象路径类型

```typescript
// 生成对象深层访问路径的字符串类型
type Paths<T, Prefix extends string = ''> = {
  [K in keyof T]: T[K] extends object
    ? `${Prefix}${string & K}` | Paths<T[K], `${Prefix}${string & K}.`>
    : `${Prefix}${string & K}`
}[keyof T]

interface Config {
  server: {
    host: string
    port: number
  }
  database: {
    url: string
    name: string
  }
}

type ConfigPaths = Paths<Config>
// 'server' | 'server.host' | 'server.port'
// | 'database' | 'database.url' | 'database.name'
```

---

### 4.4 与 infer 结合提取字符串部分

```typescript
// 提取路由参数
type ExtractRouteParams<T extends string> =
  T extends `${infer _Start}:${infer Param}/${infer Rest}`
    ? Param | ExtractRouteParams<`/${Rest}`>
    : T extends `${infer _Start}:${infer Param}`
    ? Param
    : never

type Params = ExtractRouteParams<'/users/:id/posts/:postId'>
// 'id' | 'postId'

// 提取事件名称（去掉 on 前缀）
type EventName<T extends string> = T extends `on${infer E}` ? Uncapitalize<E> : T

type ClickName = EventName<'onClick'>    // 'click'
type ChangeName = EventName<'onChange'>  // 'change'
```

## 五、实战示例

### 5.1 类型安全的 i18n

```typescript
type Messages = {
  'user.greeting': string
  'user.farewell': string
  'error.notFound': string
  'error.unauthorized': string
}

type MessageKey = keyof Messages
// 'user.greeting' | 'user.farewell' | 'error.notFound' | 'error.unauthorized'

// 提取命名空间
type ExtractNamespace<T extends string> = T extends `${infer NS}.${string}` ? NS : never
type Namespaces = ExtractNamespace<MessageKey>  // 'user' | 'error'

function t(key: MessageKey): string {
  return messages[key]
}
t('user.greeting')    // ✅
t('user.unknown')     // ❌ 类型报错
```

### 5.2 类型安全的 CSS-in-JS

```typescript
type CSSUnit = 'px' | 'em' | 'rem' | 'vh' | 'vw' | '%'
type CSSSize = `${number}${CSSUnit}`

interface StyleProps {
  fontSize?: CSSSize
  padding?: CSSSize
  margin?: CSSSize
  width?: CSSSize
  height?: CSSSize
}

const styles: StyleProps = {
  fontSize: '16px',    // ✅
  padding: '1rem',     // ✅
  width: '100%',       // ✅
  height: '200invalid' // ❌
}
```

### 5.3 Redux Action 类型生成

```typescript
type ActionCreators = {
  fetchUser: (id: number) => void
  updateUser: (id: number, data: Partial<User>) => void
  deleteUser: (id: number) => void
}

// 自动生成 Request/Success/Failure action 类型
type AsyncActions<T extends string> =
  | `${T}_REQUEST`
  | `${T}_SUCCESS`
  | `${T}_FAILURE`

type UserActions = AsyncActions<'FETCH_USER' | 'UPDATE_USER'>
// 'FETCH_USER_REQUEST' | 'FETCH_USER_SUCCESS' | 'FETCH_USER_FAILURE'
// | 'UPDATE_USER_REQUEST' | 'UPDATE_USER_SUCCESS' | 'UPDATE_USER_FAILURE'
```

## 六、注意事项

```typescript
// ⚠️ 过于复杂的模板类型可能导致 TS 编译变慢
// 避免生成太多组合
type TooManyOptions = `${string & keyof SomeHugeObject}-${string & keyof AnotherHugeObject}`

// ⚠️ 模板类型不能包含非字符串基本类型（需要 string & K 处理）
type Keys<T> = {
  [K in keyof T]: `key_${string & K}`  // 需要 string & K 排除 symbol
}[keyof T]
```

## 总结

- 模板字面量类型让字符串类型具备"计算"能力
- **内置操作**：`Uppercase`、`Lowercase`、`Capitalize`、`Uncapitalize`
- **最佳用途**：自动生成 getter/setter/事件名、路由参数提取、i18n 键名
- **与 infer 结合**：可以从字符串类型中提取子串类型
- **注意性能**：避免生成过多组合导致编译变慢
