# 事件处理

## 一、React 事件 vs 原生事件

### 1.1 语法差异

```jsx
// 原生 HTML（小驼峰，字符串）
<button onclick="handleClick()">点击</button>

// React（小驼峰，函数）
<button onClick={handleClick}>点击</button>
```

---

### 1.2 事件命名规范（小驼峰）

| 原生事件 | React 事件 |
|----------|-----------|
| onclick | onClick |
| onchange | onChange |
| onsubmit | onSubmit |
| onkeyup | onKeyUp |
| onkeydown | onKeyDown |
| onmouseenter | onMouseEnter |

---

## 二、绑定事件处理函数

### 2.1 直接写行内箭头函数

```jsx
function Button() {
  return (
    <button onClick={() => {
      console.log('点击了按钮')
      alert('Hello!')
    }}>
      点击
    </button>
  )
}
```

---

### 2.2 组件内定义函数

```jsx
function Counter() {
  const [count, setCount] = useState(0)

  // 定义处理函数
  function handleClick() {
    setCount(count + 1)
  }

  return (
    <div>
      <p>{count}</p>
      <button onClick={handleClick}>+1</button>  {/* 注意：没有 () */}
    </div>
  )
}
```

> ❌ 错误：`onClick={handleClick()}` 会在渲染时立刻执行！

## 三、事件对象（Event）

### 3.1 合成事件（SyntheticEvent）

React 事件对象是**合成事件**，不是原生事件，封装了浏览器差异，API 和原生一致。

```jsx
function handleClick(e) {
  // e 是 React 合成事件对象
  console.log(e.target)      // 触发事件的元素
  console.log(e.currentTarget) // 绑定事件的元素
  e.preventDefault()           // 阻止默认行为
  e.stopPropagation()          // 阻止冒泡
}

<button onClick={handleClick}>点击</button>
```

---

### 3.2 获取原生事件对象

```jsx
function handleClick(e) {
  const nativeEvent = e.nativeEvent  // 原生 DOM 事件对象
}
```

## 四、传递参数

### 4.1 箭头函数包裹（常用）

```jsx
function List() {
  const items = ['苹果', '香蕉', '橙子']

  function handleDelete(item) {
    console.log('删除:', item)
  }

  return (
    <ul>
      {items.map((item, index) => (
        <li key={index}>
          {item}
          {/* 箭头函数包裹，传递参数 */}
          <button onClick={() => handleDelete(item)}>删除</button>
        </li>
      ))}
    </ul>
  )
}
```

---

### 4.2 bind 方式

```jsx
<button onClick={handleDelete.bind(null, item)}>删除</button>
```

> 💡 箭头函数方式更直观，推荐使用。

---

### 4.3 同时获取参数和事件对象

```jsx
function handleClick(item, e) {
  e.preventDefault()
  console.log('点击了:', item)
}

<button onClick={(e) => handleClick(item, e)}>点击</button>
```

## 五、常见事件类型

### 5.1 鼠标事件

```jsx
function MouseDemo() {
  return (
    <div
      onClick={() => console.log('点击')}
      onDoubleClick={() => console.log('双击')}
      onMouseEnter={() => console.log('鼠标进入')}
      onMouseLeave={() => console.log('鼠标离开')}
      onMouseMove={() => console.log('鼠标移动')}
    >
      鼠标事件演示
    </div>
  )
}
```

---

### 5.2 键盘事件

```jsx
function InputDemo() {
  return (
    <input
      onKeyDown={(e) => console.log('按下:', e.key)}
      onKeyUp={(e) => console.log('抬起:', e.key)}
      onKeyPress={(e) => console.log('按键:', e.key)}
      onEnterPress={(e) => e.key === 'Enter' && console.log('回车!')}
    />
  )
}
```

---

### 5.3 表单事件

```jsx
function FormDemo() {
  return (
    <form onSubmit={(e) => {
      e.preventDefault()  // 阻止表单默认提交刷新
      console.log('提交表单')
    }}>
      <input
        type="text"
        onChange={(e) => console.log('输入:', e.target.value)}
        onFocus={() => console.log('获得焦点')}
        onBlur={() => console.log('失去焦点')}
      />
      <button type="submit">提交</button>
    </form>
  )
}
```

## 六、this 绑定问题（类组件）

函数组件不用关心 this，但是类组件需要：

```jsx
class Button extends React.Component {
  constructor(props) {
    super(props)
    // 方式一：构造函数中绑定
    this.handleClick = this.handleClick.bind(this)
  }

  handleClick() {
    console.log(this)  // this 指向组件实例
  }

  // 方式二：类字段箭头函数（推荐 ✅）
  handleClick = () => {
    console.log(this)  // 箭头函数继承外部 this
  }

  render() {
    // 方式三：行内箭头函数（每次渲染创建新函数）
    return <button onClick={() => this.handleClick()}>点击</button>

    // 方式四：行内 bind（同上，每次创建新函数）
    return <button onClick={this.handleClick.bind(this)}>点击</button>
  }
}
```

> 💡 推荐方式二：**类字段箭头函数**，代码最简洁。

## 七、事件委托

React 事件默认都绑定在 **document** 上（React 17 后绑定在 root 节点），利用了事件冒泡机制，性能更好。

```
按钮点击 → 冒泡到父元素 → ... → 一直冒泡到 root → React 分发事件
```

好处：
- 减少内存占用（不用每个元素都绑定监听器）
- 子组件新增/删除时不用重新绑定事件

## 八、常见坑点

### Q1：为什么 `onClick={handleClick()}` 会立刻执行？

```jsx
// ❌ 错误：加了 ()，渲染时就执行了
<button onClick={handleClick()}>点击</button>

// ✅ 正确：传函数本身，点击时才执行
<button onClick={handleClick}>点击</button>
```

---

### Q2：事件处理函数中读不到最新的 state？

这是因为**闭包陷阱**，后面 Hooks 章节会详细讲。解决：

```jsx
// 函数式更新
setCount(prev => prev + 1)
```

---

### Q3：怎么阻止事件冒泡？

```jsx
function handleClick(e) {
  e.stopPropagation()  // 阻止冒泡
  e.preventDefault()   // 阻止默认行为（比如链接跳转）
}
```

---

## 总结

✅ React 事件小驼峰：`onClick`、`onChange`
2. ✅ 传函数本身，不要加 `()`：`onClick={fn}`，不是 `onClick={fn()}`
3. ✅ 事件对象 `e` 是合成事件，`e.preventDefault()` 阻止默认
4. ✅ 传参用箭头函数包裹：`onClick={() => fn(arg)}`
5. ✅ 类组件注意 this 绑定，推荐类字段箭头函数写法
