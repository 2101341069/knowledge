## NGINX 核心优势

| 特性 | 说明 |
|------|------|
| **高并发** | 能够同时处理数万个并发连接（C10K 问题） |
| **低内存消耗** | 10,000 个非活动 HTTP 保持连接仅需 2.5MB 内存 |
| **高性能** | 事件驱动架构，异步非阻塞处理 |
| **热部署** | 支持配置热重载，无需重启服务 |
| **模块化** | 丰富的模块生态系统，可扩展性强 |

## 常用命令速查

```bash
# 测试配置
nginx -t

# 热重载配置
nginx -s reload

# 查看状态
systemctl status nginx

# 查看错误日志
tail -f /var/log/nginx/error.log
```
